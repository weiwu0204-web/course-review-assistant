# 评测语料与复现说明

## 为什么原始语料不在版本库中

本项目的质量评测曾使用高校真实专业课课件（Ceph 分布式存储 14 份 / 325 页、计算机网络与计算机组成原理课件）及往年试题样本。这些材料及其直接生成的复习文档、抽题文本属于第三方版权内容，不在公开仓库中跟踪（已由 `.gitignore` 忽略 `eval/*` 与本地课程目录，仅保留本说明与 `scripts/` 下的评测脚本）。

日常自动化测试（`pytest` 与 `node tests/test_coverage_ui.js`）全部使用合成课件 `tests/samples/sample_course.pptx`（由 `scripts/make_sample.py` 生成，真值已知）和模型替身，**不依赖本地私有语料，也不调用付费模型 API**。

## 本地语料目录约定（自备材料复现时）

将自有课件或试题放到本地后，下列脚本默认读写 `eval/` 或 `output/`（均已被 Git 忽略）：

| 脚本 | 用途 | 是否调用模型 | 默认输入 / 输出 |
|---|---|---|---|
| `scripts/evaluate_generation.py` | 三种提取配置（纯文本框 / 分层提取 / 分层+视觉）消融实验 | 是（支持 `--dry-run` 仅验提取） | 输入 `tests/samples/sample_course.pptx`；输出 `eval/generation_eval_results.json` |
| `scripts/step0_generate.py` | 单份真实课件端到端提取与生成探针 | 是 | 输入 `<课件.pptx>`；输出 `eval/step0_<课件名>_<模板>.md` |
| `scripts/e2e_exam_flow.py` | 往年试题「直搬真题 / 预测题」两条链路端到端验证 | 是 | 输入 `<课件.pptx> [试题路径] [direct\|predict]`；输出 `eval/e2e_*.md` |
| `scripts/verify_coverage.py` | 批任务术语覆盖率体检、回归阈值断言、与外部文档对照 | 否（纯本地零成本） | 输入 `--batch <batch_id>`，可选 `--compare <外部文档.md>` |
| `scripts/verify_repair_trigger.py` | 检查存量批次自动补漏触发门控是否误触发 | 否（纯本地零成本） | 读取 `output/` 下存量批次 |
| `scripts/p3_probe.py` | BM25 分词、召回率与延迟探针 | 改写探针调模型，纯检索零成本 | 读取本地课件目录 |
| `scripts/p3_citation_ab.py` / `p3_ab_score.py` | 有/无强制引用受控盲评实验与精确 McNemar 统计检验 | `ab` 调模型，`score` 零成本 | 输入 `eval/citation_ab/questions.json`；输出 `output/eval_citation/` |

## 已完成的评测摘要与出处

以下指标来自历史实测记录，详细实验设计、样本规模与局限性见对应归档文档：

1. **分层提取消融实验**（合成样例 `sample_course.pptx` 6 页，见 `scripts/evaluate_generation.py`）：
   - `plain`（仅文本框）：知识点召回 `9/9 (100%)`，表格/图表硬数据保留 `2/11 (18.2%)`，教师备注考点 `2/4 (50.0%)`，嵌入图片独有信息 `1/3 (33.3%)`。
   - `layered`（文本+表格+备注+公式+图表 XML，无视觉）：硬数据保留升至 `8/11 (72.7%)`，备注考点升至 `4/4 (100%)`。
   - `vision`（分层提取 + 视觉模型读嵌入图）：图片独有信息升至 `3/3 (100%)`。

2. **整课覆盖率与长程衰减对照**（Ceph 课 14 节 / 325 页，「复习指南 / 详细」档，见 [P1-COVERAGE.md](../docs/archive/desktop/P1-COVERAGE.md) 与 `scripts/verify_coverage.py`）：
   - 本项目逐节生成后汇编：平均术语覆盖率 **97.7%**（前 7 节 **98.6%** / 后 7 节 **96.9%**，前后衰减 1.7 个百分点）。
   - 通用 Agent 一次性生成整门课文档对照：平均 **89.5%**（前 7 节 **95.1%** / 后 7 节 **83.9%**，后半程衰减 11.2 个百分点）。

3. **覆盖率不足自动补漏（verify → repair 闭环）**（见 [P2-ACCEPTANCE.md](../docs/archive/desktop/P2-ACCEPTANCE.md)）：
   - 三组低覆盖样本（起点 58% / 89% / 82%）均在 3 轮内修至 **100%**，单节耗时 **9.5–11.1 秒**。
   - 补漏 Token 成本占单节生成成本 **26%–37%**（守住 40% 成本上限），边际成本约 **¥0.002 / 百分点**。
   - 存量 27 节本地回测：25 节不触发（含档位不适用批次）、2 节低覆盖应触发，**0 误触发**。

4. **课程知识库检索与引用核验**（见 [P3-RAG.md](../docs/archive/desktop/P3-RAG.md)）：
   - **BM25 按页检索**（325 chunks）：建索引 **11 ms**，暴力打分查询延迟 **p50 0.20 ms / p95 0.43 ms**；单语料探针下术语类 query Top-5 召回 **98.8%**，口语类 query 经改写后由 **92.9%** 升至 **100%**。在更严格的跨 14 份课件 20 题人工锚点页评测中，同课件命中 **18/20（90.0%）**、精确锚点页命中 **13/20（65.0%）**（误差主要来自同课件相邻页竞争）。
   - **引用自动核验**：标定集真引用通过率 **93.3%**、假引用通过率 **0.0%**；20 题真实问答共 127 条引用中可信（`supported`）**89.8%（114/127）**，编造不存在页码（`not_found`）**0 条**。
   - **强制引用对照实验（负结果如实保留）**：20 题 × 有/无引用双臂盲评，两臂严格准确率均为 **80.0%（16/20）**（McNemar `p = 1.000`），实验未支持「强制引用提升事实准确率」的假设（锚点页命中的 13 题两臂全对，呈现天花板效应），详见 [P3-RAG.md §21](../docs/archive/desktop/P3-RAG.md)。
