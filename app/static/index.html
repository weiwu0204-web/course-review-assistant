Key 是什么？怎么复制完整？

Key 相当于软件替你去调用 AI 的「钥匙」，按用量计费，是一长串字符（多数家是 sk- 开头，智谱家的不是）。

复制：在平台点 Key 右侧的「复制」按钮 → 回到这里右键粘贴（Ctrl+V）。别用鼠标拖选复制——容易漏掉头尾，验证会报「Key 无效」。

Key 等价于钱：不要发班级群、不要截图晒给别人。

常见问题

一定要花钱吗？ 不需要。各家新用户基本都送免费额度（DeepSeek、通义等），生成一份复习文档的用量很小，免费额度通常够用很久。

Key 存在哪里？会不会泄露？ 只保存在你自己电脑的本地配置文件里，软件不联网上传任何信息。

填错了 / 想换一家？ 验证时会提示具体原因；重新在设置里选服务商换 Key 即可。各家的 Key 不通用。
