### 两个会影响本项目的约束

1. **GLM-5.x 思考不可关闭**（只有 low/high/max 强度档）。
   我们的 `AI_PROVIDERS["zhipu"]["thinking_off"] = {"thinking": {"type": "disabled"}}`
   对 4.x 有效，**对 5.x 无效**。若把 zhipu 的 model 换成 5.x，需要：
   - 不再下发 `thinking_off`（否则可能被拒或静默忽略）；
   - 前端的「思考模式」开关对该家应隐藏或改为「思考强度」（当前 UI 没这个能力）。
   - ⚠️ 5.x 的具体强度参数名与取值**尚未核实**，不要凭猜写进代码。
2. **GLM-5.3-Flash 对本项目性价比可能更好**：0.8 / 2.8 比在用的 glm-4.7（2 / 8）更便宜，
   且**一个模型同时吃文本与图像**（我们目前文本/视觉是两个型号），1M 上下文、128K 最大输出。
   代价是思考关不掉（推理 token 会一直计费）。
   **是否切换是产品决策，未擅自改动**。
