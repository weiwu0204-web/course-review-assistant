## 2. 步骤 B：与通用 agent 对照自测（这是差异化的立论依据）

### 为什么必须**提前写好提示词**（不能随手问）

因为这轮对照要证明的是**结构性边界**（上下文装不下 / 无法承诺逐页覆盖 / 不可复现），
不是"谁更会写提示词"。所以：

1. **给对手的提示词要和我们自己的同等、甚至更直白**。我们自己的 system prompt 里有
   角色设定 + 7 条要求 + 风格说明 + 页码标记；如果给通用 agent 一句"帮我整理下课件"，
   那测出来的是提示词差距，不是能力边界——**结论一文不值，也不诚实**。
2. **三档用同一份提示词**，只有投喂量不同。这样变量只有一个：输入规模。
3. **明写"覆盖所有知识点"**。这恰恰是我们的核心承诺，把它也交给对手，才能真正测出
   它在规模上做不做得到（而不是靠"我们提示词里要求了覆盖"取胜）。

### 对照用提示词（照抄，三档都用这一份）

```
你是一名大学生的期末复习助手。请基于我提供的课件内容，生成一份结构化的期末复习文档。

要求：
1. 按章节/主题组织，提炼核心概念与定义
2. 列出重点公式、模型或结论
3. 标注易错点 / 易混淆概念
4. 给出建议的复习顺序
5. 用 Markdown 输出，结构清晰
6. 不要生成"深度思考题 / 开放讨论题"这类非考试型内容
7. 禁止编造课件里没有的数据、年份、题目或"老师强调过"之类的内容

另外：请务必覆盖课件里出现的所有知识点，不要遗漏页面上的内容。

【课件内容】
（把该档的课件上传或粘贴进来）
```

### 差异化定位要改口（诚实的结论）

原立论「通用 agent 上下文装不下整门课」**不成立**——glm5.3-flash 一次处理 14 节没崩。
真正站的住的是另外三条，且都被本次数据支持：

1. **覆盖率可见化**（不再只是"nice to have"，而是核心卖点）：通用 agent 的遗漏是
   **静默且随篇幅递增**的（95.6% → 83.3%），用户无从察觉；我们的价值是**把它测出来、摆出来**。
   这也解释了为什么 P1 覆盖率值得做——**它正是把这个差异变成产品功能**。
2. **每份独立请求 → 覆盖不衰减**：我们的 98.7% → 96.6% 几乎持平，因为每节各自占用一个
   请求窗口；glm 是单窗口处理全部内容，注意力随篇幅衰减。
3. **可复现 + 成本可见 + 多模态读图**：同一输入重跑结构一致；跑前知道多少钱、跑后知道
   花了多少；图片里的图表数据/YAML 能进正文。

**面试话术（可直接用）**：
> 我拿同一门 14 节的课做过对照：通用大模型能一次生成一份看起来完整的总册，
> 但逐术语测下来，前半门课覆盖 95.6%、后半门课掉到 83.3%——**它不会报错，你也不会发现**。
> 我的方案把每节拆成独立请求，覆盖率全程稳定在 97%，并且能把这个数字直接呈现给用户。

## 3. 判定标准（事先定死，避免事后找解释）

**必达（任一不过 → 不进 P1）**

1. **完整性**：14/14 份成功（允许失败后重试成功）
2. **可用性**：总册有目录、每节有出处锚点、无空节、可直接当复习材料读
3. **覆盖承诺**：抽样 5 页中 **≥4 页**的核心考点能在总册里定位到
4. **成本与时长**：实际花费 ≤ **¥2**，总耗时 ≤ **40 分钟**

**对照结论（决定差异化定位是否成立）**

- 期望：通用 agent 在第 3 档出现**明确且可复现的失败模式**（拒收 / 明显只覆盖一部分 /
  内容自相矛盾 / 编造）。记录到具体现象，不要只写"它不行"。
- **诚实项**：如果通用 agent 三档都做得住，那说明"整门课装不下"这个立论不成立，
  差异化必须改挂到**覆盖率可见化 + 可复现 + 成本可见**上——这也是有效结论，照实记。

- ✅ 但实测出**更硬的一条**：glm 的术语覆盖率**前半门课 95.6% → 后半门课 83.3%**，
  我方 98.7% → 96.6%。**它不会报错、文档看着完整，用户不可能发现后 1/3 漏了约 1/5。**
- ✅ 所以真正的差异化 = **覆盖率可见化**（把看不见的遗漏变成看得见的数字）+ 每份独立请求
  （覆盖不衰减）+ 可复现 + 成本可见 + 多模态读图。
- **P1 覆盖率可见化的优先级因此上升**：它不再是"锦上添花"，而是把上述差异做成产品功能的那一步。

**成本对照**：我方 ¥1.9517 / 12.2 分钟；glm 侧费用取决于其订阅/额度（未记录）。
我方正文是对方的 4 倍（18.4 万 vs 4.6 万字符），属于"更全但更贵"的取舍，需如实说明。

### 公平性确认（2026-09-13，用户答复）

1. **投喂方式**：glm 侧收到的是 **14 个原始课件文件**（与我们对等）。

   而我们配置里的 `thinking_off` 对 5.x 无效——详见 `PROVIDER-MODELS.md`。

### 「读图」差异的验证（同一份对照的附加发现）

既然 glm 也拿到了 14 个原始文件，就值得验证它**是否真的看到了内嵌图片**。
挑四类「只存在于图片里、文字层完全没有」的内容比对：
