# 批量生成实测指南（0.8.0 · M1 验收）

> 目的：验证「整门课 → 一份复习总册」这条链路在真实模型上能跑通。
> 预计花费：**约 ¥0.26**（3 份测试课件）；预计耗时：**2–6 分钟**（串行）。

| 项 | 状态 |
|---|---|
| API Key | `.env` 里已配置 DeepSeek（`deepseek-v4-flash` + 视觉模型），**无需在界面里再配** |
| 服务端口 | 8000 |

## 1. 启动服务

在项目根目录执行（**用项目自带的虚拟环境**）：

```bat
cd /d F:\agent_pro\ppt-reviewer
.venv\Scripts\python.exe run.py
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即成功，浏览器打开：

**http://127.0.0.1:8000**

> ⚠️ `run.py` 开着 `reload=True`：**跑的期间不要改项目里的文件**，否则服务自动重启、批任务线程会被打断（虽然能续跑，但会绕一圈，不利于第一次观察）。

## 2. 推荐测试集（3 份，共约 ¥0.26）

先做「主流程」，用这 3 份**健康**文件（都在项目根目录 / tests/samples）：

| 放进列表的顺序 | 文件 | 页 | 图 | 单份预估 |
|---|---|---|---|---|
| 1 | `课件.pptx` | 19 | 6 | ¥0.031 |
| 2 | `tests/samples/sample_course.pptx` | 6 | 1 | ¥0.008 |
| 3 | `LLM.pdf` | 130 | 0 | ¥0.222 |

**为什么选这 3 份**：第 1、2 份是 PPT（一份真实、一份合成），第 3 份是 PDF——**一次覆盖两种格式 + 大小两极**。`LLM.pdf` 有 4.3 万字，很可能触发「输出被截断」警示，这正好验证我们之前标记的边界，属**预期内行为**，不是 bug。

> 想更省，把 `LLM.pdf` 换成 `4.2_2_磁盘调度算法.pdf`——但那 4 份是坏 PDF，会走「容错测试」，别混在第一轮里。

## 3. 第一轮：主流程（按顺序核对）

### 3.1 切到批量视图
- 点页面顶部 **「整课批量」** 标签
- ✅ 预期：出现「点击选择，或一次拖入多份 .pptx / .pdf 课件」的投放区

### 3.2 选文件
- 点投放区（或把 3 个文件一起拖进去）
- ✅ 预期：出现 3 行文件，每行几秒后**自动显示** `N 页 · M 图 · 约 ¥X.XX`
- ✅ 预期：底部出现合计，例如「3 份 · 共 155 页 · 预估约 ¥0.26」

### 3.3 调整顺序（章节顺序 = 列表顺序）
- 用每行右侧的 **↑ / ↓** 调整，最终顺序与上表一致
- ✅ 预期：调序后**立即**重排；点 **✕** 能删行
- 在「课程名称」里填一个好认的名字（如 `操作系统`）——它决定总册标题与文件名

### 3.4 参数
- 模板 / 风格 / 视觉 / 思考 保持默认（复习指南 / 详细 / 勾视觉 / 不勾思考）
- ✅ 预期：勾「视觉」时每份的估价会更高（第 1 份从约 ¥0.03 起）

### 3.5 开始
- 点 **「开始批量生成」**
- ✅ 预期：弹出确认框，写着「共 3 份课件，整批预计花费约 ¥0.26… 串行生成约需 3~8 分钟。可随时停止，生成到一半的总册也能下载。」
- 点确认

### 3.6 观察运行（每 2 秒刷新）
- ✅ 预期：进入运行页，进度条 0% → 100%，逐份推进
- ✅ 预期：每行状态依次是 **等待中 → 生成中（转圈）→ 完成**，完成后显示 `N 页 · 约 ¥X`
- ✅ 预期：顶部概览随刷新累加，「已花费约 ¥…」从无到有
- ⚠️ 若某行出现 `⚠️ 输出被截断，内容可能不完整`（`LLM.pdf` 大概率命中）：**这是已知边界**，记下来即可

### 3.7 结果
- 全部完成后自动滚动到结果卡片
- ✅ 预期：出现 `总册 | 第1节 课件 | 第2节 sample_course | 第3节 LLM` 的页签栏
- 逐个点开：
  - **总册**：应有自动生成的目录、各节正文、出处锚点（不是让模型重写的，是汇编的）
  - **各节**：分别是该份课件的复习文档
- 点 **复制 / 下载 .md / 下载 .html**
- ✅ 预期：下载内容与页面一致；总册文件名为 `总复习册-<课程名>.md`

### 3.8 两个附加检查（0.8.2）

- **风格联动**：把「文档类型」切到 **习题生成** → ✅ 预期「输出风格」里**不应再有「表格化」**，
  只剩「详细 / 精简」两项，且标签由「输出风格」变为「卷面风格」。切回复习指南应恢复三项。
  （单份页与批量页都要检查，两处规则应一致。）
- **历史记录**：点 **「返回新建」** → ✅ 预期页面底部出现「历史记录」，列出以往批次
  （课程名 / 状态 / 完成份数 / 花费 / 时间）。**点一行应能重新打开它的总册与各节**；
  全失败的批次显示「无内容」且不可点。

## 4. 第二轮：容错与断点（可选，几乎不额外花钱）

### 4.1 坏文件隔离
- 回到「返回新建」，这次加入 **`4.2_2_磁盘调度算法.pdf`**（文字层损坏的那个）+ 1 份健康文件
- ✅ 预期：
  - 坏文件那行**在选完文件几秒内**就显示红色错误「文字层已损坏（中文字符无法还原成可读文本）」，且**不计入合计**
  - 点开始后，**健康那份照常完成**，坏的那份失败——**整批不被拖垮**
- 这是验证「失败单份不阻塞整批」的关键一条。

### 4.2 关页面 / 刷新续接
- 在任务**运行中**关掉浏览器标签，等 1 分钟再打开 http://127.0.0.1:8000
- ✅ 预期：自动切回批量视图、接着显示进度（任务在服务端线程里跑，与页面无关）

### 4.3 停止 / 继续
- 运行中点 **「停止」**
- ✅ 预期：提示「已请求停止：当前这份做完后就停」，当前份做完后停下，状态变「已停止」
- ✅ 预期：已完成部分的**总册仍可下载**（点结果页签）
- 点 **「继续生成」**
- ✅ 预期：只跑剩余未完成的份，**已完成的不重复跑**（这直接关系到不重复花钱）

## 5. 判读对照表

| 你看到的现象 | 说明什么 | 处理 |
|---|---|---|
| 某份估价明显偏高 | 图片多 → 视觉模型按图折 token | 正常；可关「视觉」再试同一份对比 |
| 某份出现截断警示 | 模型写满了单次输出上限（32768 token）。**与页数无关**，取决于该章内容能被展开多少 | 改用「精简」档，或把这份单独生成 |
| 坏 PDF 被拦在选文件阶段 | 健康检测生效 | 正常 |
| 坏 PDF 拦不住、真跑起来了 | 健康检测阈值不灵 | **发我**，附文件名 |
| 全部失败且提示余额/限流 | Key 或额度问题 | 按提示换家/充值 |
| 进度卡住不动超过 3 分钟 | 可能卡在某个大文件 | 发我，附服务端控制台最后 20 行 |
| 总册里某节缺失 | 该节失败（看该行错误） | 重试失败项 |
| 建批后进度停在 0/N 不动 | **0.8.1 已修**；若仍出现说明修复没生效 | **发我** |
