# 服务版架构

桌面版使用 `app.main:app`、本地配置和文件。服务版仅挂接独立 API，MySQL 保存登录会话、资源归属、版本、任务和结果引用；原文件和成品使用私有对象存储。worker 使用 API 进程之外的入口，并复用解析、生成与汇编。独立入口使两版可以分别启动和测试。

首版将数据库用作任务队列，在短事务里领取，解析/模型/对象操作都在事务外。独立对象键隔离每次生成尝试，数据库只发布当前领取者的结果。具体 schema、状态和回滚见 [服务基础规格](specs/001-courseware-revision/design.md)。

002 在原数据结构上增添学习数据：课程课件版本在建库时固定，文本分块放私有对象存储，库、问答记录和章节诊断由 MySQL 带归属管理。打开知识库时从分块重建 BM25，不共享进程内索引；问答通过 SSE 返回来源、答案和引用检查。浏览器资源位于 `app/static/service/`，桌面页面资源位于 `app/static/desktop/`，原 API 路径保持兼容。详见 [002 技术方案](specs/002-service-study/design.md)。
