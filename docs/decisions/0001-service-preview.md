# 0001：保留桌面版，独立运行服务版

状态：已采用。

桌面版的批任务、知识库、历史和统计已经可用，但状态来源依赖本地目录和当前进程。为了保住原有用户的工作流，服务版使用独立入口和独立数据。

MySQL 保存用户、版本和作业；私有对象桶保存原件和章节结果。短事务领取任务，租约和领取标记防止过期 worker 提交。对象和数据库之间没有事务：上传后才发布引用，已知冲突清理对象，提交结果不确定时保留待排查。服务版每次生成尝试仍可能产生外部调用成本。消息中间件等有负载证据再评估。

原版继续通过 `app.main:app` 运行。新服务的 API 和 worker 不挂载桌面路由，也不共享本地凭据。原有文档保留原日期和范围；服务版以新规格和运行手册为准。
