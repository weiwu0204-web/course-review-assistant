# 001 课件版本与批量生成

1. 已登录用户发布课件 v1 并提交 A。v2 发布成功后，A 固定使用 v1，新提交 B 使用 v2。发布失败不改变 v1，基于过时版本的更新返回冲突。
2. 用户只能读或更新自己的课程、课件版本和任务，只能下载自己可访问的已发布产物。跨账号请求返回未找到，未登录返回 401。
3. 第二个 API 实例可查询同一用户的任务。提交重试使用同一幂等键和参数时返回同一任务；同一键对应不同参数返回冲突。
4. 一次批任务内逐份生成、失败互不阻塞，只重试失败项。失去 worker 后，在领取到期后可以重做该项；旧领取者不能将结果发布为成功。完成后的节次按提交顺序汇编。

测试使用合成文件；真模型调用、公网接入和历史数据导入另定规格。桌面版能力按原契约回归。
