# 002 服务版学习与历史

1. 学生能从自己课程的当前课件创建知识库，且只能访问自己的库、问答和历史。非归属用户即使知道 ID 也读不到；相同上传内容不会跨账号复用问答历史。
2. 知识库使用创建时的一组课件版本。发布新版后，旧库的引用和问答仍基于旧版本。新库才使用新版本。答案以 SSE 返回来源和页码，未命中时不自行编造答案。
3. 用户可查看自己最近生成任务、各节术语覆盖率和问答次数。生成可选择补漏；术语覆盖用于排查遗漏。
4. 在浏览器能完成登录、课程与文件管理、批量生成、查询/重试、下载、建库和问答。桌面版继续使用原有入口；原有生成和问答数据留在原目录。
