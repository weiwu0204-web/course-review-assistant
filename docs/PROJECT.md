# 项目描述

## 要解决的问题

期末周复习一门课，要把这门课所有的 PPT 从头翻一遍。一个学期十几份课件、
每份几十页，真正有信息量的可能只有其中一小部分——大部分时间花在了
找「哪里是重点」上，而不是在学重点。

这个工具做的事：**上传课程 PPT → 自动提取内容 → AI 生成一份结构化的复习文档**。

## 给谁用

主要是雾围自己，以及身边同样在期末周挣扎的同学。

这个定位决定了两件事：

- **不需要登录、不需要云端存储。** 本地跑、本地存，够用就好。
- **输出必须真的省时间。** 生成的文档如果还要再翻一遍 PPT 核对，
  那这个工具就没有存在价值。这是判断所有功能的唯一标准。

## 明确的边界

**暂不做 OCR，但「多数课件有文字层」这个前提已被部分推翻。**
0.8.0 实测 5 份 PDF 课件，其中 **4 份文字层是损坏的**——由「打印成 PDF」生成，
字体 ToUnicode 映射表丢失，字形能正常显示但中文字符读不出来，对程序而言等同于
图片型（详见 [PDF-SUPPORT.md](./PDF-SUPPORT.md)）。「有文字层」不代表「能提取出文字」。

因此当前策略是**先检测、再分流**：

| 情况 | 处理 | 状态 |
|---|---|---|
| 文字层健康 | 正常提取（PPT / PDF 一致） | ✅ |
| 文字层损坏 / 扫描版 | 明确告知并拦下，**不生成垃圾文档** | ✅ |
| 真要读出内容 | 整页渲染 + OCR 或视觉模型 | ⬜ 待做 |

真处理它们时，仍倾向**整页渲染 + 视觉模型**而非纯 OCR：渲染出来能让模型理解版面，
OCR 只给一串没有结构的文字。PDF 自带渲染器（不需要 PowerPoint COM），
这条路比 PPT 侧更容易落地——见 [CV-INTEGRATION.md](./CV-INTEGRATION.md)。

**不做内置联网搜题。** 实测（2026-09-02，WebSearch）：网上只有**通用题库**
（CSDN 计网题库、英文刷题站等），搜不到任何具体某校的真题。通用题只能巩固
基础概念，学不到本校风格——而「本校风格」恰恰是期末复习最值钱的部分。
结论：题目来源按「上传本校真题 > agent 代搜通用题库 > 模型兜底模拟题」，
面向同学的 exe 只做第一种（最可靠、无网络依赖）；「帮你搜」留给 agent 场景。

**不做登录和云端。** 在证明「生成的文档好用」之前，这些是纯粹的浪费。

**不让 AI 编「思考题」。** Step 0 实测教训：模型自拟的开放式思考题
（"如果去掉表示层会怎样"）与期末考卷形态无关——每所大学有自己的出题风格，
AI 编不出"你校的风格"。复习文档里的题目要么来自真实题源，要么明示为模拟题。

## 一句话总结设计哲学

> 能免费解析出来的，就不要花钱交给模型。
>
> 能拿到真实题源的，就不要让模型自己出题。
