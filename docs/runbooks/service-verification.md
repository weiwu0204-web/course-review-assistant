要复跑跨进程演练，准备**只用于测试的空 MySQL 数据库和私有对象桶**，配置 `PPT_SERVICE_DATABASE_URL` 与存储变量，执行 `python -m scripts.service_admin migrate`，然后在 PowerShell 中执行：

```powershell
$env:PPT_SERVICE_SMOKE_CONFIRM = 'isolated'
python -m scripts.service_smoke
```

脚本会留下一次演练的合成用户、课件和结果。它需要一个没有其他待执行任务的测试环境；不会调用付费模型。真实课件的生成质量、多人问答和公网部署均不属于这次验收。
