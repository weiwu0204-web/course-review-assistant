## 下一阶段候选（003 规格，按完整 SDD + TDD + 并行 Worktree 执行）

以下方向按工程优先级排列，选定其一即可通过 `ppt-clarify → ppt-spec → ppt-tdd → ppt-review → ppt-verify` 走完留痕闭环：

1. **003-A · 存储孤儿巡检与批任务运维诊断（推荐优先）**
   - 解决 [ADR 0003](decisions/0003-object-store-without-cross-store-tx.md) 记录的残余风险：对账清理超过宽限期仍未被任何数据库版本/作业引用的孤儿对象，并提供受控的管理员任务健康摘要命令。
2. **003-B · 知识库异步建库队列与同课件相邻页重排**
   - 将大课件知识库构建接入后台作业队列，同时解决 P3 盲评实测暴露的“找对课件但被相邻页挤出 Top-5”（同文件命中 90% vs 精确锚点页 65%）问题。
3. **003-C · 服务版真实模型配额护栏与供应商验收集**
   - 增加单账号并发批次数与日预算阈值控制，完成真实商业模型在服务版下的端到端质量与异常降级验收。
